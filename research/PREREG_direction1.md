## 1. 假设

| 编号 | 假设 | 检验 |
|---|---|---|
| H1（现象） | 只用代理信号训练时，代理的假阳性率随轮次上升，第 6 轮真实成功率低于"仅标签"组 | 各轮 FP 的斜率 > 0（单侧）；S 组 vs L10 配对检验 |
| **H2（主）** | 相同标签预算 q = 10% 下，PP 优于"仅标签" | P10 vs L10，主指标，单侧配对检验，α = 0.05 |
| H3 | 只用 10% 标签的 PP 不劣于全标签 | P10 vs R0，非劣界 3 个点 |
| H4（次要） | 主动标注优于均匀标注 | A10 vs P10 |
| H5（次要） | 固定误差率的校正方法（PGBC）在策略漂移下失效 | B10 每轮估计出的误差率是否漂移；B10 vs P10 |
| H6（通用性） | ALFWorld 上复现 H2 的排序 | E4 |

H2 与 H3 用 Holm 校正，H4–H6 只报告效应量和置信区间，不作为主张的前提。

## 2. 固定设定

- **harness**：RPent + 冻结 π0.5 + SAM3，LIBERO-PRO 80 个任务；"无 oracle"补丁见工作项 W2。
- **起点**：开源 `sft/` 权重（step 563）。所有 arm 从同一权重出发；`rl-v006/` 只作为"回合内 oracle 可见"条件下的参考点。
- **训练池**：用 SFT 权重在验证 init（45–49）上、无 oracle 配置下测得成功率 ∈ [0.1, 0.9] 的任务。
- **每轮规模**：32 组 × 4 回合 = 128 回合，共 6 轮。组的抽取由 run seed 决定，所以各 arm 每轮抽到的 (task, init) 相同，可以做配对比较。第 0 轮的 rollout 全部来自同一个 SFT 策略，各 arm 共享。
- **训练超参**：沿用论文设置（lr 1e-6，global batch 128，dual-clip PPO，截断 IS 上限 2，无 KL、无熵项）。**每个回合抽 8 个 turn**（论文是 16），把训练耗时减半；所有 arm 一致。若 E0 实测训练足够快，则恢复 16，并在冻结前修改本条。
- **标签**：每轮按 q 抽取，ξ_i ~ Bernoulli(q_i)，在回合结束后抽取。q = 10% 时每个 run 约用 77 个真标签（全标签为 768 个）。
- **成功口径**：
  - **主指标 final-state**：planner 调用 `finish` 时环境处于成功状态；
  - 次要指标 sticky：回合中任意时刻成功即算，与论文口径一致。
- **代理信号**：
  - `f_self`：planner 的 `finish(status=success)` 声明；
  - `f_vlm`：开源 VLM 判官对最终 agent-view 和 wrist 图像打出的成功概率；
  - `f_learned`：用累计标签交叉拟合的逻辑回归，输入为上面两个信号加 transcript 统计量。

## 3. 实验组（arm）

| arm | 每轮奖励 / 优势的来源 | q | 种子数 |
|---|---|---|---|
| R0 | 全标签 RLOO（所有回合都揭示真值，即论文算法） | 100% | 2 |
| L10 | 仅标签：IPW 加 E1 选出的基线（等价于 λ = 0 的 PP） | 10% | 2 |
| S-self | 仅代理 `f_self` | 0 | 1 |
| S-vlm | 仅代理 `f_vlm` | 0 | 1 |
| B10 | PGBC：`f_vlm` 二值化，每轮用当轮标签重新估计假阳/假阴率后做 backward correction（比只在第 0 轮估计一次的版本更强） | 10% | 1 |
| **P10** | PP 均匀标注，代理用 `f_learned` | 10% | 2 |
| A10 | PP 主动标注（q_i ∝ √(f̂(1−f̂)) × 组内伪结局离散度，截断到 [q_min, 1]，IPW 加权） | 10%（期望值） | 2 |
| L5 / P5 | 预算扫描 | 5% | 1 |
| L25 / P25 | 预算扫描 | 25% | 1 |

共 15 个 run。如果预算紧张，砍掉的顺序为：预算扫描 → A10 的第二个种子 → S-vlm。

## 4. 在 E1 中选定、随后冻结的超参数

E1 用离线数据选出以下超参数并写入 v1。E2 中不再调整。

- **基线类型**：在 {对 r̃ 做 LOO，对 f 做 LOO，交叉拟合的 V̂(s₀)} 中选优势 MSE 最小的。L10 和 B10 在同一候选集中各自选最优，保证公平。
- **λ 的估计**：按组划分折做交叉拟合，可选是否截断到 [0, 1]。
- **q_min** ∈ {0.02, 0.05}（只用于 A10）。
- **优势尺度**：q = 10% 时，被标注回合的 r̃ 可以达到约 ±10。每个 arm 用一个常数缩放优势，使其均方根与 R0 一致。常数缩放不改变梯度方向，因此不引入偏差。另外决定是否对 r̃ 截断（截断会引入有界偏差，若采用需在论文中给出界）。

## 5. 主分析

- **评测与选点**：每个 run 在第 3、6 轮后用验证 init 的 200 回合子集选 checkpoint，选点标准为 final-state 成功率。
- **最终评测**：
  - P10、L10、R0：eval init 1–10 × 80 任务 × 2 次重复，共 1600 回合；
  - 其余 arm：800 回合。
  - 评测采用论文协议的采样设置，同时补报 T=1 采样下的结果。
- **统计检验**：按 (task, init, 重复次序) 配对，用 McNemar 精确检验，并报告配对 bootstrap 95% CI。
- **功效**：假设不一致对占 20%（论文中 RL vs SFT 为 24%）。1600 个配对时，3 个点的差异有约 85% 的功效；800 个配对时，3 个点只有约 60%，4 个点约 81%。这就是主比较要用 1600 回合的原因。

## 6. 否决线（到期检查，结果写入日志）

## 8. 算力与时间（中心估计，E0 后替换）

单轮估算的假设：
- 单回合耗时 T_ep ≈ 10 分钟，每卡并行 4 个回合，4 卡共 16 路；
- 训练样本的 prompt 中位数约 44k token（代码注释中的统计），9B 模型的前向、反向加重计算约 3.2 PFLOP/样本；
- 每卡有效算力按 120 TFLOPS 计算。72GB 这个规格不常见，型号和实际算力需要你们确认，这个数对训练耗时影响最大。

|---|---|---|---|
| 一轮 rollout（128 回合） | ≈ 1.3 h | — | — |
| 一轮训练（约 650 个 turn 样本，每回合 8 个；含 pre-pass） | ≈ 1.5 h（每回合 16 个时约 3 h） | — | — |
| 判官、build、重启等开销 | ≈ 0.5 h | — | — |

- 单回合耗时 T_ep 翻倍到 20 分钟时，rollout 和评测的时间也翻倍，合计约 45 天（未计余量）。
- 时间线：工程 4–5 周加 GPU 6–7 周，部分重叠，约 2.5–3 个月出全部数据。
  - NeurIPS 2027（约 5 月中）比较从容；

## 9. 可行性判断（主观估计）

| 环节 | 概率 | 主要依据 |
|---|---|---|
| 工程跑通（通过 K0） | ~85% | 管线本身完整，风险在 72GB 显存和 RPent 环境 |
| LIBERO 上的问题不平凡（通过 K1、K2） | ~60% | LIBERO 的成功与否视觉上很明显，去掉 oracle 后自报可能仍然很准；但 SFT 模型是看着 `terminated` 学会何时结束的，final-state 指标很可能明显下降 |
| 方法优势在离线实验中成立（通过 K3） | ~75%（以通过 K1、K2 为条件） | 只要 ρ = corr(f, r) 不太低，PP 的方差缩减是可证明的 |
| H2 在线显著 | ~60%（以前三项为条件） | 全部 RL 增益只有约 6 个点，各组差异被压缩在这个区间里，统计功效是最大风险 |
| H1 现象在 6 轮内出现 | ~45% | lr 1e-6、6 轮的策略变化很小（论文 RL 只比 SFT 多 5.9 个点），代理被"钻空子"可能来不及出现 |

- **得到完整正结果（H2 + H3）**：约 0.85 × 0.6 × 0.75 × 0.6 ≈ **23%**。再加上 H1 也成立，约 10–15%。
- **至少产出 CoRL 或 workshop 级别的结果**：约 55–60%。即使 H2 不显著，E0 的"oracle 泄漏"发现、E1 的方差分析和 E4 也足够撑起一篇。
- **首投主会中稿**：在得到完整正结果的前提下，按主会常见接收率约 35–45%；折算下来首投中稿约 10%。

提高胜率最有效的三件事：
1. **两周内完成 E0**，尽早淘汰不平凡性不够的设定；
2. **E4（ALFWorld）先行**，它便宜、统计功效高，让 H2 不完全依赖 LIBERO；
3. **如果 H1 是论文的卖点**，加一个预注册的"压力组"：S-self 用 lr 3e-6 跑 10 轮，专门检验代理被钻空子的现象（约 2 个 GPU 天）。

## 10. 需要你们确认的事

- 72GB 卡的具体型号和 bf16 实际算力（决定训练耗时）。
- RPent、LIBERO-PRO 和 π0.5 checkpoint（`RLinf-Pi05-LIBERO-130-fullshot-SFT`）能否在你们的机器上获取和安装。
- VLM 判官的选型（例如 Qwen3-VL-8B 还是更大的模型；与 π0.5、SAM3 分时使用显存）。
- 是否要加一个小规模真机或人工标注实验来支撑"标签昂贵"的叙事（不在本预注册的算力内）。
